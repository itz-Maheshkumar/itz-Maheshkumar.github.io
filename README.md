# itz-Maheshkumar.github.io

My personal portfolio site — built with plain HTML, CSS & JavaScript, hosted on GitHub Pages.

**Live site:** https://itz-maheshkumar.github.io/

## Structure
- `index.html` — single-page site (hero, about, skills, projects, certifications, contact)
- `assets/css/style.css` — terminal/hacker-themed dark styling
- `assets/js/script.js` — typing effect, mobile nav, scroll spy, matrix-rain background

## Local preview
Just open `index.html` in a browser — no build step required.
